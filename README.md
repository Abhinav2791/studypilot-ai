# StudyPilot AI 🚀
### Premium AI-Powered Personal Study Coach & Adaptive Study Planner

StudyPilot AI turns dense, overwhelming syllabi into dynamic, adaptive study schedules powered by cognitive science, spaced repetition, and real-time learning telemetry.

---

## 🌟 Key Application Features

### 1. 🌌 Cinematic Landing Experience
- Hero presentation with orbital motion graphics, dynamic glowing badges, and real-time value metrics.
- Interactive **Product Preview Tabs** (Adaptive Calendar, Neural AI Tutor, Focus Pomodoro, Diagnostic Analytics).
- Dynamic **IntersectionObserver** scroll animations for staggered entry effects.

### 2. 📊 Executive Dashboard (`/dashboard`)
- Comprehensive overview with dynamic personalized greeting based on time of day.
- Real-time statistics: Daily Planned Hours, Completion %, Nearest Exam Countdown, and Active Streak.
- Interactive Today's Tasks checklist with immediate state completion.
- Subject mastery progress bars with syllabus completion metrics.

### 3. 📅 Smart Adaptive Study Planner (`/planner`)
- **Multi-view Calendar**: Week Strip, Single Day, and Full Task List views.
- **AI Auto-Rebalance Engine**: Automatically reschedules and prioritizes low-confidence and high-urgency exam topics.
- **Task Management**: Schedule study sessions, spaced repetition revisions, postpone tasks by 1 day, or launch focused Pomodoro sessions.
- Multi-dimensional filters by subject and status.

### 4. 🤖 Neural AI Study Coach (`/coach`)
- Live conversational AI tutor tailored to syllabus comprehension.
- **High-Yield Prompts**: Mental model breakdowns (e.g. Database Normalization restaurant analogy), rapid-fire quizzes, and 14-day exam blueprints.
- **Audio Speech Synthesis**: Built-in Web Speech API voice reader to listen to pedagogical explanations.
- One-click copy for study summaries and flashcard extraction.

### 5. ⏱️ Focus Pomodoro Mode (`/focus`)
- Circular SVG countdown timer with smooth linear stroke animations.
- Presets: **Focus Sprint (25m)**, **Short Break (5m)**, **Long Break (15m)**.
- **Synthetic Ambient Soundscape Generator**: In-browser Web Audio API sound synthesizer with Brown Noise, Rain Storm, and Alpha Binaural Waves (10Hz).
- **Task Linkage**: Link the active Pomodoro to any planned syllabus task to automatically record focus hours.
- Zen Fullscreen Mode.

### 6. 📈 Performance Analytics & Mastery (`/analytics`)
- **Study Velocity & Consistency Score**: Real-time diagnostic telemetry (92% on-track).
- **Weekly Target vs Logged Hours Chart**: Visual bar comparison for daily study load.
- **30-Day Activity Heatmap**: GitHub-style activity grid showing session frequency and density.
- **Cognitive Peak Analysis**: Retention score breakdowns across Morning, Afternoon, Evening, and Night windows.

### 7. ⚙️ Preferences & Adaptive Pacing (`/settings`)
- Personalized study capacity slider (1 to 10 hours/day).
- Cognitive window selection (Morning sprint, Afternoon block, Evening deep work, Late night review).
- Dark / Light mode instant switcher.
- JSON data export and factory demo reset.

### 8. 🔐 Authentication & Quick Demo Roles (`/auth`)
- Branded authentication card with orbital illustrations.
- Instant 1-click Demo Profiles: **Computer Science & Engineering**, **Pre-Med / Biology**, **Law & Pre-Bar**.

---

## 🛠️ Technology Stack & Architecture

- **Framework**: Angular 16 (Modular Architecture)
- **Styling**: SCSS Design System with CSS Custom Properties tokens (`src/styles.scss`)
- **State Management**: Reactive RxJS `BehaviorSubject` streams with persistent local storage
- **Audio Engine**: Web Audio API (synthetic noise generation & oscillators) + Web Speech Synthesis
- **Typography**: Inter & Manrope (Google Fonts)
